# Ecosoft Web

Інтернет-магазин систем очищення води Ecosoft. Побудований на **Next.js 14** (App Router) + **TypeScript**.

## Сторінки

- **Головна** (`/`) — герой-блок, переваги, категорії, рекомендовані товари
- **Каталог** (`/catalog`) — список товарів із фільтром за категоріями
- **Картка товару** (`/catalog/[slug]`) — опис, характеристики, додавання в кошик
- **Кошик** (`/cart`) — список товарів, зміна кількості, скелет оформлення замовлення
- **Про нас** (`/about`)
- **Умови праці** (`/terms`) — оплата, доставка, гарантія, повернення
- **Контакти** (`/contacts`) — контактні дані та форма зворотного зв'язку

## Технології

- Next.js 14 (App Router, SSG)
- React 18 + TypeScript
- Кошик на React Context із збереженням у `localStorage`
- Без зовнішніх UI-бібліотек, стилі — звичайний CSS

## Запуск локально

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000).

## Збірка

```bash
npm run build
npm run start
```

## Статус

- Дані товарів — демонстраційні (`lib/products.ts`), замінюються на реальні.
- Оформлення замовлення — скелет: форма не відправляється на сервер. Інтеграцію з бекендом/оплатою буде додано згодом.
